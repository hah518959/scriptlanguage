웹 프로그래밍
-프론트엔드(유저가 보고 클릭하는 화면 구현)
html(hyper_type_markup_language), css(Cascading_style_sheet), javascript

-백엔드(화면 뒤에서 데이터 처리 및 저장, 보안)
서버언어: java,python,node.js,php등
데이터베이스: mysql, mongoDB 등

-자바스크립트-
웹의 기본 목적
다른 여러 컴퓨터에서 문서를 공유하거나 보는 목적
웹에서 다루는 문서를 웹 문서라고 함

웹 구조
WWW(World_Wide_Web), 거미줄같이 유저들이 이어진 정보 소통 망

웹 구성
-웹 서버
1. 문서, 이미지, 동영상 등 데이터 저장 관리
2. 웹 사이트를 탑재하는 컴퓨터(구글, 네이버 등)
3. 웹 클라이언트의 요청을 받아 웹 문서 전송
4. 웹 서버로 작동하도록 하는 소프트웨어 실행

웹 클라이언트
1. 사용자 인터페이스 담당
2. 웹 서버에 웹 문서를 요청하고 받아 사용자에게 출력

Internet(인터넷)
컴퓨터 연결 네트워크
=>즉 웹은 인터넷의 종류 중 하나이다.

웹 서버 소프트웨어 종류
Apache--> Apache
Window NT -->IIS

-전자 문서
워드, 한글, 메모장 등 문서
텍스트로 오디오 이미지 비디오 직접 저장

-웹 문서
html언어로 이미지 비디오 오디오를 파일에 나누어 작성되어 저장
하이퍼링크를 통해 링크 공유도 가능


*프로토콜
-http(hyper text protocol), https, file, ftp, telnet, malito, news 등

*서버 주소
-웹 페이지를 가진 컴퓨터의 인터넷 주소, IP주소

*TCP/IP 포트 번호
-서버가 브라우저로부터 접속을 기다리는 TCP/IP 포트 번호.
-프로토콜마다 다르며, HTTP의 경우 80, telnet의 경우 23

*경로명
-웹 서버 내 웹 페이지 파일의 폴더 경로

*파일 이름
-웹 페이지의 HTML 파일 이름


웹이 성공한 이유
1. 사용하기 쉬운
2. HTML 태그의 웹 페이지는 텍스트 문서
3. 아무 텍스트 편집기로 편집이 가능

html: 웹의 뼈대 역할
CSS: 화장 꾸며주기
Java Script: 동작하게 해주는 역할

html5가 출현하게 된 배경
1.웹 브라우저 사이의 치열한 경쟁으로 플러그인 등 호환성이 없는 비표준 기술이 난립했다.
2.웹에 접근하는 기긱들이 pc에서 스마트폰,인터넷 tv등으로 다양화되어, 어떤 기기에서도 작동하는 웹 페이지와 웹 어플리케이션의 새로운 표준이 필요했다.
3. 웹 문서를 구조, 모양, 인터페이스로 명확히 분리하여 작성할 수 있는 새로운 표준을 만들 필요가 있었다.

음악 연주를 하는 html5
1. 기본적으로 오디오 연주 가능
2. 모든 브라우저에서 연주됨
3. 음악 연주를 위한 특별한 플러그인은 필요X
